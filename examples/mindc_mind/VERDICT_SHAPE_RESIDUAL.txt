# per-case verdict contract in smoke_wiring_lint.py.
#
# WHAT A LINE HERE MEANS
# ----------------------
# This gate prints verdict lines, and the static scan in smoke_wiring_lint.py
# cannot see one that is emitted PER CHECKED CASE on a green run. Two shapes
# land here, and only measurement tells them apart:
#
#   * SINGLE RECAP — the gate really does publish one blanket verdict for its
#     whole corpus, so scripts/gate_assert.py grades it `asserted=1` however
#     many cases it compared. Measured examples before they were converted:
#     self_host_tc_unknown_ident_smoke compared 419 cases and reported
#     `asserted=1`; self_host_tc_shape_rules_smoke compared 160 and reported 1.
#     For these, "comment the assertions out, expect red" CANNOT go red — the
#     count and the verdict are identical either way.
#   * RUNTIME-COMPOSED TOKEN — the gate DOES report per case, through
#     `tag = "PASS" if ok else "FAIL"` inside an f-string. The shim counts every
#     one of those lines, so the runtime contract already binds it; only the
#     STATIC scan is blind, because `_template` renders an interpolation as
#     `{}`. Measured: self_host_tc_narrowing_smoke reports 17, lockstep 11,
#     self_host_narrow_param_smoke 64.
#
# deferred: this file is the honest statement of that residual instead of an
# unstated hole in the rule. UPGRADE PATH, per entry: route the per-case line
# through `gate_assert.check(cond, label)` (or put an `assert` in the case
# loop), drop the recap line's verdict token, and delete the name from this
# file. The self_host_tc_* family and self_host_float_lit_exact_smoke were
# converted exactly that way and are no longer listed. A leg-reporting gate that
# does not loop leaves instead by gaining a `--min-asserted N` (N >= 2) floor at
# its runner call sites, which smoke_wiring_lint.py reads out of the runners.
#
# THE LIST IS SHRINK-ONLY, and the lint enforces both directions:
#   * a name here that now satisfies the rule (or is pinned) -> FAIL, delete it;
#   * a name here that is not a `gate` row in SMOKE_WIRING.tsv -> FAIL, stale;
#   * a gate NOT here that violates the rule -> FAIL, fix it or add it in review.
# So the residual can only get smaller, and no new gate joins it by accident.
